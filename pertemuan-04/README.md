# Pertemuan 4 - CSS3 Layout dan Responsive Web Design

## Deskripsi
Halaman profil mahasiswa sederhana untuk memperkenalkan Indra Heriansyah. Halaman dibuat dengan HTML5 semantik dan ditata menggunakan CSS3.

## Fitur
- Navigasi menuju bagian Beranda, Tentang, dan Kontak.
- Bagian profil berisi foto, profil singkat, dan target belajar.
- Formulir kontak dengan input nama, email, semester, tanggal kunjungan, jenis pesan, topik yang diminati, program studi, dan pesan.
- Tata letak dua kolom pada layar lebar dan satu kolom pada layar dengan lebar maksimum 600 piksel.
- Gambar profil dibatasi agar menyesuaikan lebar kontainer.

## Struktur Berkas
- `index.html` — struktur dan isi halaman.
- `style.css` — warna, tata letak, gaya formulir, dan aturan responsif.
- `img/foto-profil.jpeg` — foto profil yang digunakan halaman.

## Menjalankan
Buka `index.html` di browser. Pastikan berkas `style.css` dan folder gambar berada pada lokasi yang sesuai dengan referensi di HTML.

## Pengembangan
- Perubahan yang dilakukan: menyusun halaman profil mahasiswa dengan navigasi, konten profil, formulir kontak, footer, serta tata letak responsif menggunakan CSS Grid dan media query.
- Commit dan push GitHub: belum dicatat.

## Pengujian dan Validasi
- Pemeriksaan CSS: jumlah kurung kurawal seimbang (33 pasang) dan tanda kurung fungsi seimbang (4 pasang); aturan grid dua kolom dan breakpoint 600 piksel terdeteksi.
- Perbaikan: kolom grid desktop menggunakan `minmax(0, 1fr)` untuk membantu mencegah konten melebar keluar kolom. Ditambahkan indikator fokus keyboard serta efek hover untuk navigasi dan tombol.
